# Drum Kit 🥁

An interactive Drum Kit web application that allows users to play different drum sounds using mouse clicks or keyboard keys.

## Project Overview

Drum Kit is an interactive music application built using HTML, CSS, and JavaScript.

The application displays different drum instruments, each represented by an image and assigned a specific keyboard key. When users click on a drum image or press its assigned keyboard key, the corresponding drum sound is played.

## Features

- **Multiple Drum Instruments:** Includes different drum instruments with individual sounds.
- **Individual Audio Files:** Each drum instrument has its own audio file.
- **Mouse Interaction:** Click on a drum image to play its sound.
- **Keyboard Interaction:** Press the assigned keyboard key to play the corresponding drum sound.
- **Key-to-Drum Mapping:** Every drum instrument is associated with a specific keyboard key.
- **Instant Sound Playback:** Sounds play immediately after user interaction.
- **Interactive Design:** Provides a simple and enjoyable musical experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Audio Files (MP3/WAV)

## How to Use

1. Open the project in your web browser.
2. View the available drum instruments and their assigned keyboard keys.
3. Click on any drum image to play its sound.
4. Alternatively, press the corresponding keyboard key.
5. Combine different sounds to create your own rhythms and beats.

## Project Purpose

This project was developed to practice HTML, CSS, JavaScript, keyboard event handling, mouse events, and audio playback in web applications.
